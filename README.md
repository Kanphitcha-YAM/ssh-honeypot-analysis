# ssh-honeypot-analysis

Analysis of SSH attacker behavior using honeypot logs (Cowrie) and Python

วิเคราะห์พฤติกรรมผู้โจมตี SSH จากข้อมูล honeypot โดยใช้ Python

## เป้าหมายของโปรเจค
- ศึกษาว่าผู้โจมตีและบอทมักลองรหัสผ่านอะไร เข้ามาช่วงเวลาไหน และพิมพ์คำสั่งอะไร
- สรุปข้อค้นพบเป็นกราฟและข้อเสนอแนะด้านความปลอดภัยสำหรับผู้ดูแลระบบ

## เครื่องมือที่ใช้
- Cowrie (SSH honeypot) บนเครื่องเสมือน VirtualBox แบบ host-only network
- Kali Linux (ใช้ทดสอบในแล็บของตัวเองเท่านั้น)
- Python: pandas, matplotlib, Streamlit
- ข้อมูล honeypot สาธารณะ (จะระบุแหล่งที่มาและเงื่อนไขการใช้งานด้านล่าง)
