# Week 1: เริ่มต้นโปรเจค SSH Honeypot

## สัปดาห์นี้ทำอะไร
- สร้าง GitHub repo สำหรับโปรเจค
- เริ่มเรียน Cisco Networking Academy (Introduction to Cybersecurity)
- วางแผนโปรเจคและตารางงาน 5 สัปดาห์ก่อนยื่นพอร์ต
- ติดตั้ง VirtualBox และสร้าง VM Ubuntu Server 24.04.5 LTS (ชื่อ cowrie-lab) สำเร็จ
- อัปเดตแพ็กเกจ (apt upgrade) เรียบร้อย
- ตั้ง Port Forwarding (127.0.0.1:2222 → 22) และ SSH จาก Windows เข้า VM ได้

## เรียนรู้อะไรใหม่
- Honeypot คือเซิร์ฟเวอร์ปลอมที่ล่อให้ผู้โจมตีเข้ามาเพื่อให้เราบันทึกพฤติกรรมของเขาไว้วิเคราะห์

## ติดปัญหาอะไร
- ตัวติดตั้ง Ubuntu ค้างที่หน้า Profile หลายรอบ (พิมพ์ไม่ได้ ทั้งคีย์บอร์ดจริงและ Soft Keyboard)
  แก้โดยเพิ่ม CPU เป็น 2 คอร์, ปิด KVM Paravirtualization, เพิ่ม RAM เป็น 2 GB
  ยังไม่ได้แยกทดสอบทีละตัว จึงยังไม่แน่ใจว่าตัวไหนช่วยได้จริง
- เผลอติ๊ก LVM ตอนตั้งค่าดิสก์ แก้โดยเอาติ๊กออกก่อนกดต่อ

## ผลลัพธ์
- สร้าง repo และโครงสร้างโฟลเดอร์เรียบร้อย
- มี VM พร้อมใช้งานสำหรับติดตั้ง Cowrie ในสัปดาห์หน้า

## สัปดาห์หน้า
- ติดตั้ง Cowrie บน VM แบบ host-only
- ทดสอบยิงเข้าเครื่องเสมือนของตัวเอง
